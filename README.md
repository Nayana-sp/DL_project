# Hybrid Neural Architecture for Multimodal Emotion Recognition

A PyTorch implementation for the project brief: audio + facial-video emotion classification, early fusion, late fusion, gated fusion, unimodal baselines, and robustness tests.

## Dataset and privacy
Use the official RAVDESS audio-visual speech video archives from Zenodo:
https://zenodo.org/records/1188976

RAVDESS is licensed CC BY-NC-SA 4.0. Use it only under the dataset's terms, cite Livingstone & Russo (2018), and do not redistribute raw clips. The code stores derived features and a manifest; keep raw recordings private. It does not perform identity recognition.

## 1. Install
Python 3.10 or 3.11 is recommended. Create a virtual environment, install PyTorch using the official selector for your CPU/GPU, then:

```bash
pip install -r requirements.txt
```

FFmpeg must be installed and available on PATH. Verify with `ffmpeg -version`.

## 2. Put the data in this layout
Extract the `Video_Speech_Actor_XX.zip` files into folders, e.g.:

```
data/raw/RAVDESS/
  Actor_01/
    01-01-...-01-01-01-01.mp4
  Actor_02/
    ...
```

The script searches recursively for `.mp4` files and accepts only audio-visual speech clips whose first two filename fields are `01-01`. It uses the emotion and actor fields from the RAVDESS filename convention. If your archive uses a different layout, inspect filenames and adjust `parse_ravdess_name()` in `src/preprocess.py`.

## 3. Preprocess
Start with a small subset to verify the pipeline:

```bash
python -m src.preprocess --input data/raw/RAVDESS --output data/processed --frames 8 --limit 100
```

Then preprocess all clips:

```bash
python -m src.preprocess --input data/raw/RAVDESS --output data/processed --frames 8
```

Outputs: `data/processed/manifest.csv`, `audio/*.npy` log-Mel arrays, `video/*.npy` face crops. Failed clips are logged in the manifest with status `error`. Face detection uses OpenCV Haar cascade; failed detections reuse the previous valid crop, or a center crop if no face has yet been detected. This is a practical baseline, not a production-grade face detector.

Emotion classes follow RAVDESS labels:
01 neutral, 02 calm, 03 happy, 04 sad, 05 angry, 06 fearful, 07 disgust, 08 surprised.

## 4. Train/evaluate
For a quick smoke test, use a small subset and fewer epochs:

```bash
python -m src.train --manifest data/processed/manifest.csv --model audio --epochs 2
python -m src.train --manifest data/processed/manifest.csv --model visual --epochs 2
python -m src.train --manifest data/processed/manifest.csv --model early --epochs 2
python -m src.train --manifest data/processed/manifest.csv --model late --epochs 2
python -m src.train --manifest data/processed/manifest.csv --model gated --epochs 2
```

For the full study, train with a proper actor-independent protocol. `--fold` selects a held-out actor fold from the deterministic six-fold actor split. One fold is reserved for testing, the next fold for validation, and the remaining four folds for training. This approximates the plan's 16 train / 4 validation / 4 test actors. Repeat with folds 0–5 and seeds 13, 21, 42. Run all models with identical folds and seeds.

```bash
python -m src.train --manifest data/processed/manifest.csv --model gated --fold 0 --seed 13 --epochs 30
```

The first run downloads pretrained ResNet-18 weights if not cached. If internet access is unavailable, the code falls back to randomly initialized weights and logs a warning; for research use, prefer pretrained weights.

Outputs are written to `results/<model>_fold<fold>_seed<seed>/` including metrics, per-class report, confusion matrix, checkpoint, and training curves. These are actual run outputs, not guaranteed performance.

## Models
- `audio`: audio-only CNN.
- `visual`: ResNet-18 frame encoder + mean frame pooling.
- `early`: feature-level concatenation.
- `late`: average audio-only and visual-only probabilities.
- `gated`: feature-wise adaptive gated fusion.
- `early_dropout` and `gated_dropout`: modality-dropout training variants.

## Important limitations
- This implementation uses fixed log-Mel spectrograms and sampled face crops.
- The provided script runs one actor-independent fold per command; run all six folds and aggregate metrics for the requested mean ± standard deviation.
- The starter corruption evaluator reports missing-modality and simple Gaussian-noise / blur tests. Results must be generated by running the code; do not invent numbers.
- The conflict test and bootstrap/McNemar analysis should be added after validating the main training pipeline and collecting pooled predictions.
